# sujud-game
🕋 Sujud Master - Game Edukasi PAI Kelas 7

Sujud Master adalah media pembelajaran interaktif berbasis Web/HTML5 yang dirancang khusus untuk siswa Pendidikan Agama Islam (PAI) Kelas 7 SMP/MTs. Game ini bertujuan untuk membantu siswa memahami konsep, tata cara, dan perbedaan antara Sujud Sahwi, Sujud Tilawah, dan Sujud Syukur secara menyenangkan.

📌 Deskripsi Singkat untuk Sidebar GitHub

About / Description:

Game edukasi interaktif PAI Kelas 7 berbasis HTML5 untuk mempelajari Sujud Sahwi, Sujud Tilawah, dan Sujud Syukur.

Topik / Topics (Tags):

✨ Fitur Utama

🎮 Pembelajaran Interaktif: Kuis dan tantangan seputar materi macam-macam sujud.

📱 Desain Responsif: Dapat dimainkan dengan lancar di HP, tablet, maupun laptop/komputer.

⚡ Ringan & Cepat: Dibuat menggunakan HTML, CSS, dan JavaScript tanpa memerlukan server khusus.

🎯 Umpan Balik Langsung: Memberikan skor dan penjelasan secara real-time untuk membantu pemahaman siswa.

🎯 Pokok Materi PAI Kelas 7

Game ini mencakup materi utama:

Sujud Sahwi: Lupa rakaat atau ragu-ragu dalam shalat.

Sujud Tilawah: Mendengar atau membaca ayat-ayat Sajdah.

Sujud Syukur: Memperoleh kenikmatan atau terhindar dari musibah.

🚀 Cara Menjalankan Secara Lokal

Clone repository ini:

git clone https://github.com/username-anda/sujud-master.git


Buka folder proyek:

cd sujud-master


Jalankan file game:
Buka file index.html langsung di peramban (browser) pilihan Anda (Chrome, Edge, Firefox, Safari).

🌐 Cara Menayangkannya di GitHub Pages

Anda dapat membuat game ini dimainkan secara langsung melalui link internet gratis dengan GitHub Pages:

Masuk ke halaman Repository Anda di GitHub.

Klik tab Settings (Pengaturan).

Pilih menu Pages di panel sebelah kiri.

Pada bagian Build and deployment -> Branch, pilih main atau master, lalu klik Save.

Tunggu beberapa menit, link game interaktif Anda akan aktif secara otomatis!
